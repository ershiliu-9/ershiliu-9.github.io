# Personalize this site

The site is intentionally ready to run before personal details are available. Replace the starter content in these files:

- `content_zh/config.toml` and `content/config.toml`: name, title, institution, contact links, navigation, and update date.
- `content_zh/bio.md` and `content/bio.md`: short introduction.
- `content_zh/projects.toml` and `content/projects.toml`: selected work.
- `content_zh/experience.toml` and `content/experience.toml`: timeline.
- `content_zh/cv.md` and `content/cv.md`: full résumé.
- `me.png`: replace with a portrait and update `author.avatar` in `content/config.toml` if the filename changes.

Run `npm run dev` for local editing and `npm run build` to export the static site to `out/`.

Pushes to the `main` branch of `ershiliu-9/ershiliu-9.github.io` deploy automatically to <https://ershiliu-9.github.io/> through GitHub Actions.
